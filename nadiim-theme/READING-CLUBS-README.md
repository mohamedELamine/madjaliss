## 🎯 نظرة عامة

نظام نوادي القراءة هو **Custom Post Type** كامل يسمح بإنشاء وإدارة نوادي القراءة مع تفاصيل شاملة:
- معلومات النادي الأساسية
- موقع الاجتماع مع خريطة تفاعلية
- جدول اللقاءات
- روابط التواصل الاجتماعي (فيسبوك، تيليجرام، موقع)
- وصف كامل ومختصر

**مهم:** النظام **لا يتضمن إدارة أعضاء** - هو مخصص لعرض معلومات النادي فقط.

## 📖 الاستخدام

### إنشاء نادي قراءة جديد

1. **اذهب إلى:** `نوادي القراءة` → `إضافة جديد`
2. **أدخل:**
   - العنوان
   - المحتوى الأساسي (اختياري)
   - الصورة البارزة
3. **في صندوق "تفاصيل نادي القراءة":**
   - أدخل الوصف المختصر (يظهر في الأرشيف)
   - أدخل الوصف الكامل (HTML)
   - أدخل عنوان موقع الاجتماع
   - أدخل إحداثيات الموقع (يمكن الحصول عليها من Google Maps)
   - أدخل ملاحظة جدول اللقاءات
   - أدخل روابط التواصل الاجتماعي
4. **انشر**

### كيفية الحصول على إحداثيات الخريطة

#### من Google Maps:
1. افتح [Google Maps](https://maps.google.com)
2. ابحث عن الموقع
3. انقر بزر الماوس الأيمن على النقطة
4. اختر "نسخ الإحداثيات"
5. الصق في حقول lat/lng

**مثال:** `36.7538, 3.0588`
- **lat** (خط العرض): `36.7538`
- **lng** (خط الطول): `3.0588`

### استخدام خريطة iframe جاهزة

إذا أردت استخدام خريطة Google Maps مُضمَّنة:

1. افتح Google Maps
2. ابحث عن الموقع
3. انقر "مشاركة" → "تضمين خريطة"
4. انسخ كود iframe
5. الصقه في حقل "كود iframe للخريطة"

## 💾 البيانات المخزنة

### هيكل club_meta

جميع البيانات تُخزن في meta واحدة باسم `club_meta` بصيغة JSON:

```json
{
  "short_description": "وصف مختصر",
  "full_description": "<p>وصف كامل بـ HTML</p>",
  "meeting_location": {
    "address": "مكتبة المدينة – وسط الجزائر",
    "lat": 36.7538,
    "lng": 3.0588
  },
  "meeting_schedule_note": "نلتقي كل سبت على الساعة 18:00",
  "facebook_page": "https://facebook.com/club",
  "telegram_channel": "https://t.me/club",
  "website": "https://club.com",
  "contact_email": "info@club.com",
  "map_embed": "<iframe src='...'></iframe>",
  "visibility": "public"
}
```

### الحصول على البيانات برمجياً

```php
$club_meta = get_post_meta( get_the_ID(), 'club_meta', true );

// الوصول للحقول
$address = $club_meta['meeting_location']['address'];
$lat = $club_meta['meeting_location']['lat'];
$lng = $club_meta['meeting_location']['lng'];
$facebook = $club_meta['facebook_page'];
```

## 🧪 المحتوى التجريبي

### استيراد النوادي التجريبية

الملف `clubs-demo.json` يحتوي على 3 نوادي جاهزة:
1. نادي القراءة الأسبوعي
2. نادي الأدب العربي الحديث
3. نادي القراءة الفلسفية

#### طريقة الاستيراد اليدوي:

1. افتح `clubs-demo.json`
2. انسخ بيانات كل نادي
3. أنشئ نادي جديد في الإدارة
4. الصق البيانات في الحقول المناسبة

#### طريقة الاستيراد البرمجي:

أنشئ ملف PHP مؤقت في مجلد القالب:

```php
<?php
// import-demo-clubs.php
require_once 'wp-load.php';

$json = file_get_contents( __DIR__ . '/clubs-demo.json' );
$data = json_decode( $json, true );

foreach ( $data['clubs'] as $club ) {
    $post_id = wp_insert_post( array(
        'post_title'   => $club['title'],
        'post_content' => $club['content'],
        'post_excerpt' => $club['excerpt'],
        'post_status'  => $club['status'],
        'post_type'    => 'reading_clubs',
    ) );

    if ( $post_id ) {
        update_post_meta( $post_id, 'club_meta', $club['meta'] );
        echo "تم إنشاء: " . $club['title'] . "\n";
    }
}

echo "تم الاستيراد بنجاح!";
```

ثم شغّل الملف مرة واحدة واحذفه.

## 🔧 استكشاف الأخطاء

### المشكلة: صفحة 404 عند زيارة النادي

**الحل:**
1. اذهب إلى `الإعدادات` → `الروابط الدائمة`
2. احفظ التغييرات (بدون تعديل)
3. حاول مرة أخرى

### المشكلة: الخريطة لا تظهر

**الحل:**
1. تحقق من أن lat/lng محددان
2. افتح Console المتصفح وتحقق من أخطاء JavaScript
3. تحقق من تحميل Leaflet CSS/JS

### المشكلة: التنسيقات لا تعمل

**الحل:**
1. تحقق من وجود ملف `assets/css/clubs.css`
2. امسح الذاكرة المؤقتة للمتصفح
3. تحقق من Console للبحث عن أخطاء 404

    $clubs = new WP_Query( $args );

        while ( $clubs->have_posts() ) {

}
