## 📌 التفعيل الأولي

### الخطوة 1: تحديث الروابط الدائمة
بعد تفعيل/تحديث الموضوع، قم بما يلي:

```
لوحة التحكم WordPress
  ↓
الإعدادات
  ↓
الروابط الدائمة
  ↓
احفظ التغييرات (دون تغيير أي شيء)
```

هذا يضمن تسجيل نوع المحتوى بشكل صحيح.

### الخطوة 2: التحقق من القائمة
تأكد من ظهور قائمة "الإصدارات" في الشريط الجانبي للوحة التحكم.

✅ **النظام جاهز للاستخدام!**

## ➕ إضافة إصدار جديد

### الطريقة الكاملة (موصى بها)

#### 1. الانتقال لصفحة الإضافة
```
لوحة التحكم → الإصدارات → إضافة جديد
```

#### 2. المعلومات الأساسية

**العنوان** (مطلوب)
```
مثال: خطوات نحو القراءة - دليل عملي
```

**المحتوى** (محرر WordPress)
```
أدخل الوصف التفصيلي للإصدار، الفهرس، ملخص الفصول، إلخ.
يمكن استخدام العناوين، القوائم، والتنسيقات المختلفة.
```

**المقتطف** (اختياري لكن موصى)
```
ملخص قصير يظهر في الأرشيف والبحث.
مثال: "دليل شامل للمبتدئين في عالم القراءة..."
```

**الصورة المميزة** (صورة الغلاف)
```
• انقر "تعيين صورة مميزة"
• ارفع صورة بأبعاد 3:4 (مثلاً 600×800)
• استخدم صورة عالية الجودة للغلاف
```

#### 3. ملء ميتا بوكس "بيانات الإصدار"

##### القسم الأول: المعلومات الأساسية

**تاريخ الإصدار** (مطلوب)
```
اختر التاريخ من التقويم
```

**نوع الإصدار** (مطلوب)
```
• كتاب
• مجلة
• كتيب
• تقرير
• عدد
```

**اللغة**
```
افتراضي: العربية
يمكن اختيار: الإنجليزية، الفرنسية، أخرى
```

**عدد الصفحات**
```
مثال: 184
```

##### القسم الثاني: المؤلفون

**إضافة مؤلف:**

1. **نوع المؤلف**:
   - **اسم حر**: لإدخال يدوي
   - **مستخدم مسجل**: لربط بحساب WP

2. **إذا اخترت "اسم حر"**:
   ```
   اسم المؤلف: أحمد بن علي
   رابط المؤلف (اختياري): https://author-website.com
   ```

3. **إذا اخترت "مستخدم مسجل"**:
   ```
   اختر من القائمة المنسدلة
   ```

4. **إضافة مؤلف آخر**:
   ```
   انقر زر "إضافة مؤلف"
   ```

##### القسم الثالث: ملف الإصدار

**رفع ملف التحميل:**
```
1. انقر "رفع ملف"
2. اختر PDF/EPUB/MOBI من جهازك
3. أو اختر من مكتبة الوسائط
4. انقر "استخدام هذا الملف"
```

**صيغ الملف المتوفرة:**
```
☑ PDF
☑ EPUB
☐ MOBI
☐ AZW

(حدد جميع الصيغ التي رفعتها)
```

##### القسم الرابع: معلومات إضافية

**ISBN** (اختياري)
```
مثال: 978-1-234-56789-0
```

**السعر** (اختياري)
```
مثال: مجاني
أو: 50 ريال
```

**مقتطف قصير** (اختياري)
```
نص قصير يظهر في البطاقة
مثال: "دليل موجز لبدء رحلة القراءة وبناء عادة يومية..."
```

**رابط المعاينة المضمنة** (اختياري)
```
مثال: https://issuu.com/.../embed
أو رابط Google Drive Viewer
```

##### القسم الخامس: صور المعاينة

**إضافة صور:**
```
1. انقر "إضافة صور معاينة"
2. اختر عدة صور من صفحات الإصدار
3. يمكن إزالة أي صورة بالنقر على ✕
```

**توصيات:**
- 3-5 صور من صفحات مختلفة
- دقة جيدة (1200px عرض أو أكثر)
- تغطي محتوى الإصدار

#### 4. التصنيفات والوسوم

**التصنيفات:**
```
مثال: أدب، تطوير ذات، تاريخ
```

**الوسوم:**
```
مثال: قراءة، عادات، مهارات
```

#### 5. النشر

**خيارات:**
```
• نشر مباشرة: زر "نشر"
• مسودة: زر "حفظ كمسودة"
• جدولة: اختر تاريخ مستقبلي
```

## 🎨 إعداد صفحة الإصدارات

### 1. ضبط عدد الإصدارات

```
المظهر → تخصيص → إعدادات الإصدارات → إعدادات الأرشيف
  ↓
عدد الإصدارات في الصفحة: 12 (افتراضي)
```

### 2. إضافة قسم الإصدارات للصفحة الرئيسية

```
المظهر → تخصيص → إعدادات الإصدارات → قسم الإصدارات في الصفحة الرئيسية
  ↓
☑ إظهار قسم الإصدارات
  ↓
عنوان القسم: أحدث الإصدارات
وصف القسم: استعرض أحدث الكتب والمجلات والإصدارات
عدد الإصدارات المعروضة: 6
تخطيط العرض: شبكة (Grid)
```

### 3. إضافة للقائمة

```
المظهر → القوائم
  ↓
أضف "الإصدارات" من "الأرشيفات"
  ↓
احفظ القائمة
```

## 💡 نصائح مهمة

### 📸 الصور

**صورة الغلاف (الصورة المميزة):**
- نسبة 3:4 (عمودي)
- دقة موصى بها: 600×800 أو أكبر
- صيغة: JPG أو PNG
- حجم: أقل من 500 KB

**صور المعاينة:**
- صفحات واضحة من الإصدار
- 3-5 صور كافية
- دقة جيدة للقراءة

### 📄 الملفات

**صيغ مدعومة:**
- PDF (موصى به)
- EPUB
- MOBI
- AZW

**أفضل الممارسات:**
- اضغط الملف للحجم المناسب
- تأكد من جودة النص
- اختبر التحميل قبل النشر

### 🔤 النصوص

**العنوان:**
- واضح ومباشر
- 3-10 كلمات مثالي
- تجنب العناوين الطويلة جداً

**المقتطف:**
- 15-30 كلمة
- جذاب ويلخص المحتوى
- يشجع على القراءة

**المحتوى:**
- استخدم العناوين والفقرات
- أضف فهرس المحتويات
- اذكر أبرز المميزات

### 🏷️ التصنيف

**التصنيفات:**
- استخدم 1-3 تصنيفات رئيسية
- تصنيفات عامة وواسعة

**الوسوم:**
- 3-7 وسوم
- محددة ودقيقة
- تساعد في البحث

## ❓ أسئلة شائعة

### س: كيف أضيف أكثر من مؤلف؟
**ج:** انقر زر "إضافة مؤلف" أسفل آخر صف مؤلف.

### س: ماذا لو لم يكن لدي ملف للتحميل؟
**ج:** يمكنك ترك حقل الملف فارغاً. لكن يُفضل إضافة رابط معاينة بدلاً منه.

### س: هل يمكن تحميل أكثر من صيغة؟
**ج:** حالياً يدعم النظام ملف واحد، لكن يمكنك تحديد الصيغ المتوفرة. في المستقبل قد يتم دعم ملفات متعددة.

### س: كيف أخفي عداد التحميلات؟
**ج:** المظهر → تخصيص → إعدادات الإصدارات → إعدادات التحميل → أزل علامة "عرض عداد التحميلات"

### س: الصفحة تظهر 404؟
**ج:** اذهب لـ الإعدادات → الروابط الدائمة → احفظ التغييرات
