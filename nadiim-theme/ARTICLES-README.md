# 📝 نظام المقالات المحسّن - WordPress Posts System

نظام متكامل لإدارة وعرض المقالات في قالب ووردبريس كلاسيكي، بدون استخدام ACF أو أي إضافات خارجية.

## ✨ المميزات الرئيسية

### 📊 نظام Meta Box المتقدم
- **وقت القراءة المقدر**: حساب تلقائي أو يدوي لوقت القراءة
- **ملف صوتي**: رفع وإدارة ملفات صوتية للمقالات (MP3, WAV, OGG)
- **مشغل صوتي مخصص**: واجهة جميلة وسهلة الاستخدام مع عناصر تحكم كاملة
- **خيارات العرض**: التحكم في إظهار/إخفاء عناصر المقال

### 🎨 تصميم احترافي
- **صفحة مقال**: تصميم نظيف ومريح للقراءة (max-width: 900px)
- **شريط تقدم القراءة**: يتتبع موضع القارئ في المقال
- **مربع تعريف الكاتب**: عرض معلومات الكاتب مع صورة ونبذة
- **دعم التعليقات**: تصميم محسّن لنظام التعليقات
- **دعم RTL كامل**: متوافق تمامًا مع اللغة العربية

### 🔍 صفحة أرشيف مع فلاتر متقدمة
- **فلترة حسب**: التصنيف، الوسم، الكاتب، وقت القراءة
- **بحث نصي**: في عناوين ومحتوى المقالات
- **ترقيم الصفحات**: نظام pagination احترافي
- **عرض البطاقات**: تصميم جميل للبطاقات مع صور مميزة

### 🎧 مشغل الصوت المتقدم
- تشغيل/إيقاف مؤقت
- شريط تقدم تفاعلي
- عرض الوقت (الحالي/الإجمالي)
- التحكم في الصوت والسرعة
- زر التحميل
- حفظ موضع التشغيل تلقائيًا

### 🌐 تحسين محركات البحث (SEO)
- **Schema.org JSON-LD**: بيانات منظمة للمقالات
- **Open Graph Tags**: للمشاركة على وسائل التواصل
- **Twitter Cards**: عرض جميل عند المشاركة
- **Breadcrumbs Schema**: مسار التنقل

## 🚀 التثبيت والإعداد

### 1. التفعيل التلقائي
النظام مدمج تلقائيًا في القالب ويعمل بمجرد تفعيل القالب!

تم تضمين جميع الملفات في `functions.php`:
```php
// تضمين نظام Meta Box للمقالات
require_once NADIIM_THEME_DIR . '/inc/article-meta.php';

// تضمين نظام الفلترة للأرشيف
require_once NADIIM_THEME_DIR . '/inc/articles-filters.php';

// تضمين Schema.org للمقالات
require_once NADIIM_THEME_DIR . '/inc/articles-schema.php';
```

### 2. التحقق من التثبيت
1. افتح صفحة إضافة/تحرير مقال جديد
2. يجب أن تشاهد ميتا بوكس "إعدادات المقال الإضافية" في الأسفل
3. جرّب رفع ملف صوتي واحسب وقت القراءة
4. احفظ المقال واعرضه في الواجهة

## 📖 دليل الاستخدام

### إضافة مقال جديد

#### 1. في صفحة التحرير (Admin)

**وقت القراءة:**
- اكتب المحتوى أولاً
- اضغط "احسب تلقائياً" للحصول على وقت القراءة
- أو أدخل الوقت يدوياً في حقل "الوقت المخصص"

**الملف الصوتي:**
- اضغط "رفع ملف صوتي"
- اختر ملف MP3, WAV, أو OGG
- أضف مدة الملف (اختياري) بصيغة: `15:30`
- أضف وصف للملف (اختياري)

**خيارات العرض:**
- ✅ عرض وقت القراءة في الواجهة
- ✅ عرض المشغل الصوتي في الواجهة

#### 2. في الواجهة (Frontend)

سيظهر المقال بتصميم احترافي يتضمن:
- شريط تقدم القراءة في الأعلى
- وقت القراءة وعدد الكلمات
- مشغل صوتي (إن وُجد)
- محتوى المقال بتنسيق مريح
- مربع تعريف الكاتب
- نظام التعليقات

### استخدام الفلاتر في صفحة الأرشيف

زُر `/blog/` أو صفحة الأرشيف وستجد:

**الفلاتر المتاحة:**
- **التصنيف**: اختر تصنيف محدد
- **الوسم**: فلترة حسب الوسوم
- **الكاتب**: عرض مقالات كاتب محدد
- **وقت القراءة**:
  - أقل من 5 دقائق
  - 5-10 دقائق
  - أكثر من 10 دقائق
  - مع صوت فقط
- **البحث**: ابحث في العناوين والمحتوى

**الاستخدام:**
1. اختر الفلاتر المطلوبة
2. اضغط "تطبيق الفلاتر"
3. لإلغاء الفلاتر: اضغط "إعادة الضبط"

## 🎨 التخصيص

### تغيير الألوان

عدّل CSS Variables في `assets/css/articles.css`:

```css
:root {
    --color-primary: #339063;        /* اللون الأساسي */
    --color-primary-dark: #2a7850;   /* اللون الداكن */
    --color-text-main: #1C2D27;      /* لون النص */
    --container-max: 900px;           /* عرض الحاوية */
    --content-max: 720px;             /* عرض المحتوى */
}
```

### تخصيص حساب وقت القراءة

في `inc/article-meta.php` غيّر معدل القراءة (حالياً 200 كلمة/دقيقة):

```php
$auto_reading_time = ceil( $word_count / 200 ); // 200 كلمة/دقيقة
```

### إضافة حقول إضافية

في `inc/article-meta.php` أضف حقول جديدة:

```php
// في دالة nadiim_article_meta_box_callback()
<div class="nadiim-meta-field">
    <label>حقل جديد</label>
    <input type="text" name="article_meta[new_field]" value="...">
</div>

// في دالة nadiim_save_article_meta()
$article_meta['new_field'] = sanitize_text_field( $_POST['article_meta']['new_field'] );
```

## 🎯 استيراد المحتوى التجريبي

يوجد 6 مقالات تجريبية جاهزة في `demo/articles-demo.json`.

### الطريقة اليدوية (نسخ/لصق)
1. افتح `demo/articles-demo.json`
2. انسخ محتوى كل مقال
3. أضف مقال جديد في ووردبريس
4. الصق العنوان، المحتوى، والمقتطف
5. أضف التصنيفات والوسوم
6. في ميتا بوكس، أضف وقت القراءة والملف الصوتي

### الطريقة البرمجية (مستقبلاً)
يمكن إنشاء script PHP لاستيراد المحتوى تلقائياً:

```php
$json = file_get_contents( NADIIM_THEME_DIR . '/demo/articles-demo.json' );
$data = json_decode( $json, true );

foreach ( $data['posts'] as $post_data ) {
    $post_id = wp_insert_post( array(
        'post_title'   => $post_data['title'],
        'post_content' => $post_data['content'],
        'post_excerpt' => $post_data['excerpt'],
        'post_status'  => $post_data['status'],
        'post_type'    => 'post',
    ) );

    // حفظ article_meta
    update_post_meta( $post_id, 'article_meta', $post_data['meta'] );

    // إضافة التصنيفات والوسوم
    // ...
}
```

## 🐛 استكشاف الأخطاء

### المشكلة: ميتا بوكس لا يظهر
**الحل:**
- تأكد من تضمين `inc/article-meta.php` في `functions.php`
- تحقق من وجود أخطاء PHP في error log

### المشكلة: رفع الملف الصوتي لا يعمل
**الحل:**
- تأكد من تحميل `articles-admin.js` بشكل صحيح
- افتح Console في المتصفح وابحث عن أخطاء JavaScript
- تأكد من تفعيل `wp_enqueue_media()` في Admin

### المشكلة: CSS لا يظهر
**الحل:**
- امسح cache المتصفح
- تحقق من مسار ملف CSS في `functions.php`
- تأكد من وجود `articles.css` في المسار الصحيح

### المشكلة: الفلاتر لا تعمل
**الحل:**
- تأكد من تضمين `inc/articles-filters.php`
- تحقق من رابط الصفحة (يجب أن يكون home أو archive)
- تأكد من عدم وجود تعارض مع إضافات أخرى

### الأداء

### التوافقية
- لا يتعارض مع إضافات SEO (Yoast, Rank Math)
- متوافق مع page builders (Elementor, Gutenberg)
- يعمل مع أي قالب ووردبريس كلاسيكي
