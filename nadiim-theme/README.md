# قالب نديم - Nadiim WordPress Theme

قالبٌ هادئ ورصين لمواقع الحوارات الفكرية والإصدارات ونوادي القراءة، مصمم بعناية للمحتوى العربي.

## 📋 نظرة عامة

**نديم** هو قالب ووردبريس كلاسيكي مُصمم خصيصاً للمواقع الثقافية والفكرية العربية. يوفر القالب بيئة هادئة وأنيقة لعرض الحوارات والمقابلات، الإصدارات والكتب، ونوادي القراءة، مع دعم كامل للغة العربية واتجاه RTL.

**الإصدار:** 1.0.0
**متطلبات ووردبريس:** 5.0 أو أحدث
**متطلبات PHP:** 7.4 أو أحدث
**الترخيص:** GPL v2 أو أحدث

## ✨ المميزات الرئيسية

### 🎨 التصميم
- تصميم هادئ ورصين مع لون أساسي #339063
- دعم كامل للغة العربية واتجاه RTL
- مسافات واسعة بين الأقسام (48-64px)
- ظلال ناعمة وزوايا مستديرة
- خطوط Cairo و Tajawal الأنيقة
- تصميم متجاوب بالكامل (Mobile-First)

### 📦 أنواع المحتوى المخصصة (Custom Post Types)

#### 1. الحوارات (howarat)
- دعم الحوارات المرئية والصوتية والمكتوبة
- حقول مخصصة: التاريخ، نوع الوسيط، رابط الوسيط، الموقع
- المشاركون (ربط مع المستخدمين)
- نص الحوار الكامل (Transcript)
- تصنيفات: نوع الحوار، موضوع الحوار
- دعم YouTube, Vimeo, SoundCloud
- Schema.org markup للسيو

#### 2. الإصدارات (esdar)
- عرض الكتب والنشرات والبحوث
- حقول مخصصة: المؤلف، تاريخ النشر، ISBN، عدد الصفحات، الناشر
- روابط: ملف PDF، رابط الشراء، رابط المعاينة
- تصنيفات: نوع الإصدار، موضوع الإصدار
- Schema.org markup للكتب

#### 3. نوادي القراءة (reading_clubs)
- إدارة نوادي القراءة بشكل كامل
- المشرف والأعضاء (ربط مع المستخدمين)
- الكتاب الحالي (ربط مع الإصدارات)
- جدول الاجتماعات
- روابط الانضمام والاجتماعات
- الحد الأقصى للأعضاء

#### 4. الاستفسارات (inquiries)
- تخزين رسائل نموذج الاتصال
- يُنشأ تلقائياً عند إرسال نموذج الاتصال
- غير ظاهر في الواجهة الأمامية

### 📄 صفحات مخصصة

#### الصفحة الرئيسية (home.php)
أقسام قابلة للتخصيص عبر المخصص:
- قسم Hero (عنوان، وصف، زر، صورة خلفية)
- أحدث الحوارات

- آخر المقالات
- نوادي القراءة

#### صفحة الكاتب (author.php)

- تبويبات: المقالات، الحوارات، الإصدارات
- روابط التواصل الاجتماعي

#### صفحة من نحن (template-about.php)
- محتوى قابل للتحرير
- خط زمني Timeline (قابل للتخصيص)
- إحصائيات تلقائية (عدد الحوارات، الإصدارات، النوادي)

#### صفحة اتصل بنا (template-contact.php)
- نموذج اتصال شامل
- حفظ تلقائي للرسائل في CPT الاستفسارات
- إرسال بريد إلكتروني للمدير
- عرض معلومات التواصل (قابلة للتخصيص)

## 📥 التثبيت

### الطريقة الأولى: عبر لوحة التحكم

1. قم بتسجيل الدخول إلى لوحة تحكم ووردبريس
2. اذهب إلى **المظهر** ← **قوالب** ← **إضافة جديد**
3. اضغط على **رفع قالب**
4. اختر ملف `nadiim-theme.zip`
5. اضغط على **التثبيت الآن**
6. بعد اكتمال التثبيت، اضغط على **تفعيل**

### الطريقة الثانية: عبر FTP

1. قم بفك ضغط ملف `nadiim-theme.zip`
2. ارفع مجلد `nadiim-theme` إلى `/wp-content/themes/`
3. من لوحة التحكم، اذهب إلى **المظهر** ← **قوالب**
4. فعّل قالب **نديم**

### بعد التثبيت

1. اذهب إلى **الإعدادات** ← **روابط دائمة** واضغط على **حفظ التغييرات** (لتفعيل روابط CPTs)
2. قم بإنشاء القوائم: **المظهر** ← **القوائم**
   - القائمة الرئيسية
   - قائمة الفوتر
3. خصص القالب: **المظهر** ← **تخصيص**

## 🔧 دليل الاستخدام

### إنشاء الحوارات

1. من لوحة التحكم: **الحوارات** ← **أضف جديد**
2. أدخل عنوان الحوار والمحتوى
3. حدد صورة مميزة
4. في قسم **تفاصيل الحوار**:
   - حدد تاريخ الحوار
   - اختر نوع الوسيط (مرئي/صوتي/مكتوب)
   - أضف رابط الفيديو أو الصوت (YouTube, Vimeo, SoundCloud)
   - حدد موقع الحوار
   - أضف نص الحوار الكامل
5. في قسم **المشاركون**: اختر المشاركين من قائمة المستخدمين
6. حدد التصنيفات: **نوع الحوار** و **موضوع الحوار**

### إنشاء الإصدارات

1. من لوحة التحكم: **الإصدارات** ← **أضف جديد**
2. أدخل عنوان الإصدار والوصف
3. حدد صورة الغلاف (صورة مميزة)
4. في قسم **تفاصيل الإصدار**:
   - أدخل اسم المؤلف
   - حدد تاريخ النشر
   - أدخل ISBN وعدد الصفحات
   - حدد اسم الناشر
   - أضف روابط: ملف PDF، الشراء، المعاينة
5. حدد التصنيفات: **نوع الإصدار** و **موضوع الإصدار**

### إنشاء نوادي القراءة

1. من لوحة التحكم: **نوادي القراءة** ← **أضف جديد**
2. أدخل اسم النادي والوصف
3. حدد صورة مميزة
4. في قسم **تفاصيل النادي**:
   - اختر المشرف من المستخدمين
   - اختر الأعضاء (متعدد)
   - حدد الكتاب الحالي من الإصدارات
   - أدخل جدول الاجتماعات
   - أضف رابط الاجتماع (Zoom, Meet, إلخ)
   - أضف رابط الانضمام للنادي
   - حدد الحد الأقصى للأعضاء

### إنشاء الصفحات المخصصة

#### صفحة من نحن
1. **الصفحات** ← **أضف جديد**
2. عنوان الصفحة: "من نحن"
3. من **قوالب الصفحة**: اختر **من نحن**
4. أضف المحتوى الأساسي
5. لإضافة الخط الزمني: **المظهر** ← **تخصيص** ← **صفحة من نحن** ← **الخط الزمني**

#### صفحة اتصل بنا
1. **الصفحات** ← **أضف جديد**
2. عنوان الصفحة: "اتصل بنا"
3. من **قوالب الصفحة**: اختر **اتصل بنا**
4. أضف أي محتوى إضافي (اختياري)
5. قم بتخصيص معلومات التواصل: **المظهر** ← **تخصيص** ← **صفحة اتصل بنا**

### تخصيص الصفحة الرئيسية

1. **الإعدادات** ← **القراءة**
2. اختر **صفحة ثابتة**
3. **صفحة المدونة**: أنشئ صفحة جديدة واختر قالب "Blog"
4. لتخصيص أقسام الصفحة الرئيسية:
   - **المظهر** ← **تخصيص** ← **الصفحة الرئيسية**
   - خصص كل قسم حسب رغبتك

### القوائم ومناطق الودجت

#### القوائم المدعومة:
- **القائمة الرئيسية**: تظهر في الهيدر
- **قائمة الفوتر**: تظهر في الفوتر

#### مناطق الودجت:
- **عمود فوتر 1**
- **عمود فوتر 2**
- **عمود فوتر 3**
- **عمود فوتر 4**

## 🎨 التخصيص المتقدم

### إضافة ألوان مخصصة

يمكنك تعديل ملف `style.css` وتغيير متغيرات CSS:

```css
:root {
    --color-primary: #339063;           /* اللون الأساسي */
    --color-primary-dark: #2a7850;      /* اللون الأساسي الداكن */
    --color-primary-light: #4dbd87;     /* اللون الأساسي الفاتح */
    --color-text-primary: #2c3e50;      /* لون النص الأساسي */
    --color-text-secondary: #7f8c8d;    /* لون النص الثانوي */
    --color-bg-light: #fafafa;          /* خلفية فاتحة */
}
```

### إضافة خطوط مخصصة

في ملف `functions.php`، قسم `nadiim_enqueue_scripts()`:

```php
wp_enqueue_style(
    'custom-font',
    'https://fonts.googleapis.com/css2?family=YourFont:wght@400;600;700&display=swap',
    array(),
    null
);
```

ثم في `style.css`:

```css
:root {
    --font-primary: 'YourFont', -apple-system, BlinkMacSystemFont, sans-serif;
}
```

## 🐛 استكشاف الأخطاء

### الصور لا تظهر بشكل صحيح
- تأكد من رفع الصورة المميزة لكل منشور
- اذهب إلى **الأدوات** ← **إعادة توليد الصور المصغرة**

### روابط CPTs لا تعمل (404)
- اذهب إلى **الإعدادات** ← **روابط دائمة**
- اضغط على **حفظ التغييرات** (بدون تغيير أي شيء)

### القوائم لا تظهر
- تأكد من إنشاء القوائم في **المظهر** ← **القوائم**
- حدد موقع القائمة: "القائمة الرئيسية" أو "قائمة الفوتر"

### مشكلة في اتجاه RTL
- تأكد من ضبط لغة الموقع إلى العربية في **الإعدادات** ← **عام**
