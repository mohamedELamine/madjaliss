# نظام الإصدارات (Releases System) - التوثيق الكامل

## 📚 نظرة عامة

نظام الإصدارات (esdar) هو نظام متكامل لإدارة وعرض الكتب، المجلات، الكتيبات، التقارير والنشرات في موقع نديم. تم بناؤه بدون ACF مع تخزين جميع البيانات في JSON واحد في post_meta.

---

## 🎯 المميزات الرئيسية

### 1. نوع محتوى مخصص (CPT)
- **Slug**: `esdar`
- **يدعم**: العنوان، المحتوى، المقتطف، الصورة المميزة، المؤلف، المراجعات
- **أيقونة**: `dashicons-book-alt`
- **أرشيف عام**: نعم
- **REST API**: مفعّل

### 2. أنواع الإصدارات
- **كتاب** (book)
- **مجلة** (magazine)
- **كتيب** (brochure)
- **تقرير** (report)
- **عدد** (issue)

### 3. الحقول المخصصة
جميع الحقول محفوظة في JSON واحد بمفتاح `esdar_meta`:

```json
{
  "release_date": "2025-11-20",
  "release_type": "book",
  "release_authors": [
    {
      "type": "user",
      "id": 1,
      "name": "أحمد محمد",
      "link": ""
    }
  ],
  "release_file_id": 123,
  "release_file_url": "https://...",
  "release_preview_embed": "https://...",
  "release_isbn": "978-1-234-56789-0",
  "release_pages": 184,
  "release_language": "ar",
  "release_excerpt": "وصف قصير",
  "release_preview_images": [45, 46, 47],
  "release_download_count": 125,
  "release_price": "مجاني",
  "release_format": ["pdf", "epub", "mobi"]
}
```

### 4. المؤلفون (Authors)
نظام مرن لإضافة المؤلفين:
- **مستخدم مسجل**: يربط بحساب WordPress
- **اسم حر**: إدخال يدوي مع رابط اختياري
- **متعدد**: يمكن إضافة أكثر من مؤلف

## 🚀 البدء السريع

### 1. التفعيل
النظام مفعّل تلقائياً بعد تحديث الموضوع. فقط قم بتحديث Permalinks:
```
لوحة التحكم > الإعدادات > الروابط الدائمة > حفظ التغييرات
```

### 2. إضافة إصدار جديد
1. اذهب إلى **الإصدارات > إضافة جديد**
2. أدخل العنوان والمحتوى
3. أضف صورة الغلاف (الصورة المميزة)
4. املأ حقول "بيانات الإصدار":
   - تاريخ الإصدار
   - نوع الإصدار
   - المؤلفون
   - ملف التحميل (PDF/EPUB/MOBI)
   - معلومات إضافية (ISBN، الصفحات، اللغة، إلخ)
5. انشر الإصدار

### 3. عرض الإصدارات
- **صفحة الأرشيف**: `https://yoursite.com/esdar/`
- **إصدار مفرد**: `https://yoursite.com/esdar/book-title/`

### التخطيطات

#### صفحة المفرد (single-esdar.php)
- **Hero Section**: صورة الغلاف + معلومات رئيسية
- **مقتطف قصير**: في صندوق مميز
- **قسم المعاينة**: iframe أو معرض صور

- **إصدارات ذات صلة**: grid بـ 6 إصدارات

#### صفحة الأرشيف (archive-esdar.php)
- **Hero**: عنوان ووصف
- **Filter Bar**: فلترة حسب النوع، السنة، التصنيف
- **Grid**: 3 أعمدة على desktop، 2 على tablet، 1 على mobile
- **Pagination**: ترقيم الصفحات

## 🔧 الدوال المساعدة

### الحصول على بيانات إصدار
```php
$meta = nadiim_get_esdar_meta( $post_id );
echo $meta['release_type'];     // نوع الإصدار
echo $meta['release_isbn'];     // ISBN
```

### الحصول على رابط التحميل
```php
$download_url = nadiim_get_esdar_download_url( $post_id );
if ( $download_url ) {
    echo '<a href="' . esc_url( $download_url ) . '">تحميل</a>';
}
```

### عرض المؤلفين
```php
// مع روابط
echo nadiim_get_esdar_authors( $post_id, '، ', true );

// بدون روابط
echo nadiim_get_esdar_authors( $post_id, '، ', false );
```

### الحصول على أحدث الإصدارات
```php
$releases = nadiim_get_recent_esdar( 6 );
if ( $releases->have_posts() ) {
    while ( $releases->have_posts() ) {
        $releases->the_post();
        // عرض الإصدار
    }
    wp_reset_postdata();
}
```

### زيادة عداد التحميل
```php
nadiim_increment_esdar_download_count( $post_id );
```

### الحصول على نوع الإصدار
```php
$type_label = nadiim_get_esdar_type_label( 'book' );  // "كتاب"
$type_icon = nadiim_get_esdar_type_icon( 'magazine' ); // SVG
```

## 📊 تتبع التحميلات

### الآلية
- عند النقر على زر التحميل، يتم إرسال طلب AJAX
- يتم زيادة العداد بشكل آمن
- يُستخدم transient لمنع التكرار من نفس المستخدم خلال ساعة
- IP المستخدم يُحفظ كـhash للخصوصية

### تعطيل التتبع
```php
// في Customizer: إعدادات الإصدارات > إعدادات التحميل
// أو برمجياً:
add_filter( 'pre_option_esdar_track_downloads', '__return_false' );
```

## 🐛 حل المشاكل (Troubleshooting)

### الإصدارات لا تظهر
1. تحديث Permalinks: `الإعدادات > الروابط الدائمة > حفظ`
2. التأكد من نشر الإصدار (ليس مسودة)
3. التحقق من عدم وجود conflicts مع plugins

### الميتا بوكس لا يظهر
1. التأكد من تفعيل الملف في `functions.php`
2. مسح الكاش
3. التحقق من صلاحيات المستخدم

### التحميل لا يعمل
1. التأكد من رفع الملف بشكل صحيح
2. التحقق من permissions المجلد
3. فحص console للأخطاء JS

### الأنماط لا تظهر
1. التأكد من تحميل `esdar.css` في Inspect > Network
2. مسح الكاش
3. التحقق من عدم وجود CSS conflicts
